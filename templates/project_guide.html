🌱 AgriNevo Project Guide

AgriNevo is a smart, web-based Agriculture Automatic Monitoring System designed to centralize important farming operations into a single digital platform. The system combines farmer management, crop management, weather monitoring, sensor monitoring, irrigation scheduling, motor control, activity records, analytics and AI-assisted features.

The main objective of AgriNevo is to reduce manual effort, improve farm monitoring, organize agricultural data and help farmers make better decisions using real-time information and historical records.

🌾 Smart Farming 🌦️ Weather Monitoring 🌡️ Sensor Monitoring 💧 Smart Irrigation 🚰 Motor Control 📊 Analytics 🤖 AI Assisted 🔐 Role Based Access

💡 1. What is AgriNevo?

AgriNevo is an Agriculture Automatic Monitoring System developed to provide farmers with a centralized platform for managing farming-related information and activities.

In traditional farming, information such as crop details, irrigation schedules, weather conditions, motor activity and previous farming records may be maintained separately. AgriNevo brings these activities together in one system.

The application follows a web-based architecture where the frontend provides the user interface, the Flask backend handles application logic, SQLite stores structured data, external APIs provide weather information, and JavaScript components such as Chart.js are used for visualization.

The system can also be extended in the future with real IoT sensors, automatic irrigation hardware, advanced AI models, mobile notifications and intelligent crop recommendations.

🧩 5. Detailed System Modules

Complete explanation of every major AgriNevo module

👤

1. Farmer Registration & Login

This module provides the entry point to the system. It allows a farmer to create an account and later access the application using valid login credentials.

⚙️ How It Works
  1. The farmer opens the registration page.
  2. Required information is entered into the registration form.
  3. The Flask backend receives the submitted form data.
  4. Input information is validated before processing.
  5. The farmer record is stored in the SQLite database.
  6. During login, the entered credentials are checked against stored data.
  7. After successful authentication, a user session is created.
  8. The user is redirected to the appropriate dashboard.
Input: Username, password and farmer information.
Processing: Flask validates and authenticates the user.
Storage: Farmer information is maintained in the database.
✅ Output: Registered farmer with authenticated system access.
🧑‍🌾

2. Farmer Profile Management

The Farmer Profile module provides a personalized area where the logged-in farmer can view and manage profile information.

⚙️ How It Works
  1. The system identifies the currently logged-in farmer.
  2. Farmer information is retrieved from the database.
  3. The information is displayed through a profile template.
  4. The farmer can edit permitted profile information.
  5. Updated information is submitted to the Flask backend.
  6. The database record is updated.
  7. The latest information is displayed on the profile page.
Input: Profile details and optional profile image.
Processing: Flask retrieves and updates farmer records.
Storage: Farmer profile information is stored in SQLite.
✅ Output: Personalized digital farmer profile.
📊

3. Smart Dashboard

The dashboard acts as the central control center of AgriNevo. It summarizes the most important farm information so that the farmer does not need to open every module separately.

⚙️ How It Works
  1. The authenticated user opens the dashboard.
  2. Flask collects required information from the database and services.
  3. Crop information is prepared for display.
  4. Weather information can be displayed.
  5. Motor status and irrigation information can be summarized.
  6. Quick action cards provide navigation to important modules.
  7. The dashboard presents the information using responsive cards.
✅ Output: A complete overview of the current farm system.
🌾

4. Crop Management

Crop Management works as a digital crop register. It allows the farmer to maintain organized information about crops instead of relying completely on manual records.

⚙️ How It Works
  1. The farmer opens the Crop Management page.
  2. Crop-related information is entered.
  3. Flask receives and validates the submitted information.
  4. A new crop record is inserted into SQLite.
  5. Stored crops are retrieved and displayed in the crop list.
  6. The farmer can edit an existing crop record.
  7. Unwanted records can be deleted when required.
Input: Crop name and related crop information.
Processing: Flask performs CRUD operations.
Database: Crop records are stored in SQLite.
✅ Output: Organized digital crop management system.
🌡️

5. Sensor Monitoring

Sensor Monitoring is designed to monitor important agricultural parameters such as temperature, humidity and soil moisture. These parameters are useful for understanding the current environmental condition of the farm.

⚙️ How It Works
  1. Sensor values are received by the application.
  2. The backend processes the received values.
  3. Values can be stored as monitoring records.
  4. The latest readings can be displayed on the monitoring page.
  5. Historical readings can be used for analysis.
  6. Threshold conditions can be used to generate alerts.
  7. In a future IoT implementation, physical sensors can provide live readings.
Parameters: Temperature, humidity and soil moisture.
Processing: Backend receives, validates and prepares sensor data.
Future: Real IoT sensors can be connected to the system.
✅ Output: Environmental condition monitoring and historical data.
🌦️

6. Weather Information

The Weather module connects AgriNevo with an external weather service so that users can view current weather information without leaving the application.

⚙️ How It Works
  1. The user selects or opens the weather section.
  2. Flask sends a request to the configured weather API.
  3. The external service processes the request.
  4. A JSON response is received.
  5. The backend extracts required weather values.
  6. Information such as temperature, humidity and weather description is prepared.
  7. The values are displayed through responsive weather cards.
Source: External Weather API.
Format: JSON response.
Display: Temperature, humidity and weather condition.
✅ Output: Current weather information inside the farming system.
💧

7. Irrigation Scheduling

The Irrigation Scheduling module helps organize when irrigation should start, when it should end and how long the irrigation activity should continue.

⚙️ How It Works
  1. The farmer opens the irrigation scheduling section.
  2. A crop or farming activity is selected.
  3. Start time and end time or duration are entered.
  4. The Flask backend validates the schedule information.
  5. The schedule is stored in the irrigation schedule table.
  6. Saved schedules are retrieved and displayed.
  7. The schedule can be used as a reference for motor operation.
✅ Output: Organized irrigation timetable for farm activities.
🚰

8. Motor / Pump Control

This module manages the ON/OFF state of the irrigation motor or pump and maintains an activity record for later analysis.

⚙️ How It Works
  1. The farmer selects the ON or OFF control.
  2. The browser sends a request to the Flask route.
  3. The backend processes the requested motor state.
  4. The current state is updated in the application.
  5. The activity is recorded with relevant timing information.
  6. The dashboard can show the latest motor status.
  7. Motor records can later be used for analytics.
Input: Motor ON/OFF command.
Backend: Flask motor-control routes.
Record: Motor state, time and related activity information.
✅ Output: Motor status and recorded irrigation activity.
📡

9. Live Farm Monitoring

Live Farm Monitoring provides a consolidated view of important farm conditions and operational states from one screen.

⚙️ How It Works
  1. The backend retrieves the latest available farm information.
  2. Current sensor information is prepared.
  3. Motor status is collected.
  4. Weather information can be included.
  5. Irrigation information can be displayed.
  6. The data is presented using live-style monitoring cards.
✅ Output: Consolidated farm monitoring screen.
📜

10. Records & History

The Records module maintains historical information about farming activities. Historical records are important because they allow users to review what happened previously.

⚙️ How It Works
  1. An activity occurs within the application.
  2. The backend captures relevant information.
  3. Date and time information can be associated with the activity.
  4. The record is stored in the database.
  5. The Records page retrieves previous entries.
  6. The farmer can review historical activities.
  7. Selected records can be removed when required.
✅ Output: Digital history of farm activities.
📈

11. Analytics & Reports

Analytics converts stored farm activity into meaningful statistics and visual representations. This makes large amounts of historical data easier to understand.

⚙️ How It Works
  1. The Flask backend retrieves relevant database records.
  2. Records are filtered and processed.
  3. Motor ON/OFF counts can be calculated.
  4. Duration and other statistics can be derived.
  5. The processed values are passed to the template.
  6. JavaScript and Chart.js convert the values into graphs.
  7. The farmer can visually understand historical activity.
Backend: Flask + database queries.
Processing: Counts, duration and statistical calculations.
Frontend: Chart.js visualizations.
✅ Output: Charts, statistics and meaningful farming insights.
🔔

12. Alerts & Notifications

The Alerts module is designed to notify the farmer when an important condition requires attention.

⚙️ How It Works
  1. A threshold or condition is defined.
  2. The system receives or reads the current value.
  3. The current value is compared with the defined condition.
  4. If the condition is satisfied, an alert is generated.
  5. The alert can be displayed on the dashboard or notification section.
  6. Future versions can send mobile or email notifications.
✅ Output: Timely warnings, reminders and farming notifications.
🤖

13. AI-Assisted Disease Detection

The AI Disease Detection module is designed to assist farmers in identifying possible crop or plant diseases from uploaded leaf or crop images.

⚙️ How It Works
  1. The farmer uploads a crop or leaf image.
  2. Flask receives and validates the uploaded file.
  3. The image is prepared for AI analysis.
  4. An AI model or AI service analyzes visual patterns.
  5. The system receives a predicted or possible disease indication.
  6. The result is returned to the user interface.
  7. The farmer can use the result as an initial indication and take appropriate agricultural action.
Input: Leaf or crop image.
Processing: Image analysis using an AI model/service.
Output: Possible disease classification or indication.
🤖 Important: AI results should be treated as assistance, not as a guaranteed agricultural diagnosis.
🛡️

14. Admin Module & Role-Based Access

The Admin module provides separate access for system-level management. Role-based access helps prevent normal users from accessing administrator-only functionality.

⚙️ How It Works
  1. A user logs into the system.
  2. The backend identifies the user's role.
  3. The role is checked before protected pages are opened.
  4. An administrator can access administrator functionality.
  5. A normal farmer is redirected to the farmer dashboard.
  6. Unauthorized access to restricted routes can be blocked.
✅ Output: Separate and controlled Admin and Farmer access.

🏆 12. Final Project Summary

AgriNevo demonstrates how web technologies can be applied to agriculture to create a centralized digital farming platform. Instead of treating crop management, weather monitoring, irrigation, motor operation and farm records as completely separate activities, the system brings them together through a common interface.

The combination of Flask, SQLite, frontend technologies, external APIs, analytics and AI-ready architecture makes AgriNevo suitable as a foundation for a larger smart farming solution.

The ultimate goal is to make agricultural monitoring more organized, data-driven and easier to manage while providing a clear path toward future IoT and AI integration.
